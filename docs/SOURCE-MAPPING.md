All templates retain a `sourceRef` on each field for traceability. Some source PDFs are scanned/flattened and have inconsistent labels/numbering (for example repeated A11/A17/A18 labels in the Fibre sheet); the template keys are unique application keys while the displayed labels preserve the field meaning.

The CCTS summary sheets include PAT-style normalization / REC rows as shown in the supplied documents. They are retained in the CCTS templates rather than being removed based on framework name.
